Design system

Paws & Hearts UI Kit

The single source of truth for the shelter's visual language — warm paper surfaces, Georgia for display paired with Inter for body, one earthen accent, and a small set of semantic states. Every swatch and component below is the real token or class used across the site, not a reimplementation.

Color

Every surface, line, and label resolves to a token. Never hard-code a value; when you need a tint, mix on a token with color-mix().

Neutrals

--fg#201914

--muted#7a6d63
--meta#9b5b32
--border#ded2c3

Accent

--accent#9b5b32
--accent-on#ffffff

--accent-hover and --accent-active are derived from --accent via color-mix with black (8% / 14%)with white (12% / 20%), so hover moves away from the dark ground instead of into it.

14 · Patterns

Principles

A short list of what the system is for — and what it isn't.

Do

  • One accent — earthen, used sparingly.
  • Track all caps to 0.06em or more.
  • Write real copy; no placeholder lorem.
  • Fill charts from real figures.
  • Warm paper surfaces, soft borders.
  • Use the glyph set for icons.

Don't

  • Indigo or neon gradients.
  • Emoji as icons.
  • Rounded card with a coloured left border.
  • Invented metrics or stock numbers.
  • Stark white surfaces.
  • More than one primary per viewport.
