Built on one system

One palette, one type pairing, every page

Warm paper backgrounds, Georgia for display and Inter for body, and a single earthen accent — the same tokens re-used page to page so the shelter reads as one place, not four websites.

Warm, not clinical

Paper-toned surfaces and soft borders instead of stark white — the shelter feels lived-in, not institutional.

Calm hierarchy

Serif display for headlines, a restrained scale, and generous space let each page breathe before it asks anything of you.

Honest placeholders

Where a real photo or figure belongs, the glyph tile says so plainly — no invented numbers, no stock imagery.
